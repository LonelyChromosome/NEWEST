# research-topic-midterm

Project giữa kỳ môn Thiết kế Web nâng cao.

## Công nghệ

- Node.js
- Express
- EJS
- SQLite
- Mô hình MVC

## Chức năng

- Hiển thị danh sách đề tài
- Thêm đề tài
- Tìm kiếm theo mã, tên đề tài, sinh viên, lĩnh vực
- Sửa đề tài
- Xóa đề tài bằng POST
- SQLite lưu dữ liệu thật

## Chạy

```bash
npm install
npm start
```

Truy cập:

`http://localhost:3000/topics`

SQLite được khởi tạo tự động tại `data/database.sqlite`.
